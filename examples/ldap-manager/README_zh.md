# LDAP Manager 视频制作示例

**[English](README.md)**

这是一个实际的产品介绍视频制作案例，展示完整的工作流程。

## 视频信息

- **产品**: LDAP Manager - 多节点账户管理平台
- **时长**: 约 2 分 5 秒 (125 秒)
- **分辨率**: 1920x1080 @ 30fps

## 视频结构

| 段落 | 时间 | 时长 | 内容 |
|------|------|------|------|
| 片头 | 0:00-0:10 | 10秒 | Logo动画 + 产品名 + 副标题 |
| 功能亮点 | 0:10-0:18 | 8秒 | 6个功能卡片展示 |
| 演示 | 0:18-1:55 | 97秒 | 完整功能演示录屏 |
| 片尾 | 1:55-2:05 | 10秒 | Logo + 口号 + 行动按钮 |

## 演示内容

录屏演示覆盖以下功能：

1. **运行统计** - 30天认证趋势图表
2. **节点切换** - 多节点数据查看
3. **TAB切换** - 认证统计/数据同步统计
4. **服务状态** - 节点服务状态监控
5. **账号管理** - 导航和列表展示
6. **账号查询** - 按用户名搜索
7. **认证记录** - 查询用户认证历史
8. **批量操作** - 选择并开放账号
9. **数据导出** - 导出 Excel

## 文件说明

- `FinalVideo.tsx` - Remotion 视频组件
- `record_final_v3.js` - Playwright 录屏脚本
- `generate_final_voiceover.py` - 配音生成脚本
- `timeline_v3.json` - 录屏时间线记录

## 关键经验

### 1. 分镜确认流程

制作过程中经历了 3 次分镜调整：
- 第1版：缺少片头、功能演示不完整
- 第2版：添加服务状态颜色说明、批量操作演示
- 第3版：最终确认版本

**教训**: 必须在用户明确确认分镜后才开始录制

### 2. 时间偏移计算

```
录屏事件时间 + 18秒 (片头+功能亮点) = 最终视频时间
```

例如：
- 录屏 20.8秒 页面加载完成 → 最终视频 38.8秒
- 录屏 45.5秒 点击账号管理 → 最终视频 63.5秒

### 3. 配音同步

配音时间必须精确计算，每段配音都要对应正确的画面时间段。

## 使用此示例

可以参考这些文件作为模板，根据自己的产品进行修改：

1. 修改 `record_final_v3.js` 中的测试数据和操作步骤
2. 修改 `generate_final_voiceover.py` 中的配音文字和时间线
3. 修改 `FinalVideo.tsx` 中的场景组件和品牌元素
