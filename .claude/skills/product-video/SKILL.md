# 产品介绍视频生成技能

## 适用场景

- 为 Web 应用创建产品介绍/演示视频
- 需要包含：片头动画、功能录屏、中文配音、片尾动画
- 输出格式：MP4 (1920x1080, 30fps)

## 工作流程

```
┌─────────────────────────────────────────────────────────────┐
│  Phase 1: 分镜设计                                           │
│  ├── 分析产品功能和目标受众                                    │
│  ├── 设计视频结构（片头/功能亮点/演示/片尾）                     │
│  ├── 编写分镜脚本和配音文案                                    │
│  └── 【必须】等待用户确认分镜脚本                               │
├─────────────────────────────────────────────────────────────┤
│  Phase 2: 素材准备                                           │
│  ├── 启动开发服务器（前后端）                                   │
│  ├── 执行 Playwright 录屏脚本                                 │
│  ├── 记录时间线（每个操作的精确时间戳）                          │
│  └── 转换视频格式 (WebM → MP4)                                │
├─────────────────────────────────────────────────────────────┤
│  Phase 3: 配音生成                                           │
│  ├── 计算配音时间线（录屏时间 + 偏移量）                         │
│  ├── 生成各段配音音频 (edge-tts)                              │
│  ├── 合并配音到单个音轨 (FFmpeg adelay)                        │
│  └── 验证配音时长匹配                                          │
├─────────────────────────────────────────────────────────────┤
│  Phase 4: 视频合成                                           │
│  ├── 创建 Remotion 视频组件                                   │
│  ├── 组合：片头 + 功能亮点 + 录屏 + 片尾 + 配音                  │
│  ├── 渲染最终视频                                             │
│  └── 清理临时文件                                             │
├─────────────────────────────────────────────────────────────┤
│  Phase 5: 验收交付                                           │
│  ├── 打开视频供用户审查                                        │
│  ├── 根据反馈调整                                             │
│  └── 最终交付                                                 │
└─────────────────────────────────────────────────────────────┘
```

## 关键原则

### 1. 分镜先行，确认再做

**绝对禁止**直接开始录制！必须：
1. 先制定详细分镜脚本
2. 包含：时间线、画面描述、操作步骤、配音文字
3. 用户明确确认后才开始制作

### 2. 音画同步优先

配音时间计算公式：
```
最终视频时间 = 录屏事件时间 + DEMO_START
DEMO_START = 片头时长 + 功能亮点时长
```

### 3. 单次连续录制

- 设计完整操作流程后一次性录制
- 录屏脚本必须包含 TimelineRecorder
- 避免多段录制后剪辑拼接

### 4. 时间线驱动

录屏输出 `timeline.json`，配音脚本读取时间线生成同步配音。

## 技术栈

| 需求 | 推荐方案 | 备选方案 |
|------|----------|----------|
| 视频合成 | Remotion | FFmpeg 纯命令行 |
| 浏览器录屏 | Playwright | Puppeteer |
| 中文配音 | edge-tts (免费) | Azure TTS (付费) |
| 音频处理 | FFmpeg | - |

## 视频结构模板

### 标准产品介绍视频 (2分钟)

```
00:00-00:10  片头动画
             - Logo 弹性缩放 + 光环效果
             - 产品名称 (spring 动画)
             - 一句话定位 (打字机效果)
             配音: "欢迎使用 [产品名]，[一句话定位]"

00:10-00:18  功能亮点
             - 4-6 个功能卡片依次出现
             - 图标 + 标题 + 简短描述
             配音: "我们为您提供...[功能概述]"

00:18-01:55  核心演示
             - 完整的功能操作录屏
             - 各功能点配音同步
             配音: 根据录屏时间线生成

01:55-02:05  片尾动画
             - Logo + 发光效果
             - 口号文字
             - 行动号召按钮
             配音: "[产品名]，[口号]！立即开始使用吧！"
```

## 文件结构规范

```
project/
├── public/
│   ├── recordings/
│   │   ├── full_demo.mp4          # 完整录屏
│   │   └── timeline.json          # 时间线记录
│   └── audio/
│       ├── synced_voiceover.mp3   # 合并后的配音
│       └── voiceover_metadata.json # 配音元数据
├── src/
│   ├── FinalVideo.tsx             # 主视频组件
│   ├── scenes/                    # 场景组件
│   └── components/                # 可复用组件
├── scripts/
│   ├── record_demo.js             # 录屏脚本
│   └── generate_voiceover.py      # 配音生成脚本
└── out/
    └── final.mp4                  # 最终输出
```
